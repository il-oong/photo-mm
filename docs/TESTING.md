# 실제 아이폰 확인 목록

자동 테스트와 별개로 실제 기기의 터치·사진 접근·공유 동작을 확인합니다.
아래 항목은 확인 전 목록이며, 완료된 테스트 결과를 의미하지 않습니다.

- [ ] 첫 실행에서 사진을 선택하면 편집 화면이 열린다.
- [ ] 사진 선택을 취소해도 오류 없이 목록으로 돌아온다.
- [ ] iCloud 사진을 가져오는 동안 진행 표시가 나오며 실패 시 안내가 나온다.
- [ ] 세로·가로·회전된 HEIC 사진이 올바른 방향으로 보인다.
- [ ] 시작점·끝점을 누르고 1250을 입력하면 1,250 mm로 표시된다.
- [ ] 빈 값, 0, 음수는 적용되지 않고 소수점 값은 저장된다.
- [ ] 각 색상 및 글자 크기를 바꿔 적용하면 사진과 내보낸 이미지에 반영된다.
- [ ] 한글 메모를 추가하고 수정·삭제할 수 있다.
- [ ] 수정 모드에서 치수선 양 끝점과 메모를 이동할 수 있다.
- [ ] 확대 후에도 터치한 위치와 치수 위치가 일치한다.
- [ ] 화면 회전 후에도 치수와 메모가 사진의 같은 위치에 남는다.
- [ ] 되돌리기가 추가·수정·삭제·이동에 적용된다.
- [ ] 저장하고 닫은 뒤 앱을 재실행해 숫자와 스타일을 다시 수정할 수 있다.
- [ ] 미저장 상태에서 닫으면 저장·버리기·계속 편집을 선택할 수 있다.
- [ ] 이미지 공유에서 메시지·파일 저장·사진 저장 및 취소가 정상 작동한다.
- [ ] 작은 아이폰 화면, 큰 글자 설정, 가로 화면에서도 적용·취소 버튼이 보인다.
- [ ] 사진 가장자리의 메모와 치수 글자가 잘리지 않는다 (짧은 메모 기준).

사진 앱의 공유 메뉴에서 Photo MM을 여는 기능은 아직 구현하지 않았습니다.
