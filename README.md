# Photo MM

아이폰 사진과 스크린샷 위에 줄자로 잰 치수와 텍스트 메모를 기록하는 앱입니다.

> 현재 상태: 기획 단계입니다. 앱 기능은 아직 구현되지 않았습니다.

## 확정된 요구사항

- 줄자로 직접 잰 값을 입력합니다. 사진에서 실제 길이를 자동 측정하지 않습니다.
- 치수 단위는 mm로 고정합니다. 예: 1,250 mm
- 사진 위에 치수선을 배치하고 측정값을 표시합니다.
- 텍스트 메모를 추가합니다.
- 선 색상과 글자 크기를 조절할 수 있습니다.

## 첫 버전 개발 방향

1. 앱에서 사진 또는 스크린샷 선택
2. 두 지점을 선택하여 치수선 추가
3. mm 측정값 입력 및 메모 추가
4. 선 색상과 글자 크기 조절
5. 편집 내용 저장 및 표시된 이미지 공유

원본 사진과 편집 정보를 별도로 보관하여 저장 후에도 치수와 메모를 수정할 수 있도록 설계할 예정입니다.

## 후속 검토

- 사진 앱의 공유 메뉴에서 가져오기
- 확대 편집, 실행 취소, 마지막 스타일 기억
- 현장별 사진 분류 및 PDF 내보내기

스크린샷 촬영 직후 앱을 자동 실행하는 방식은 iOS 제약이 있어 첫 버전의 전제로 삼지 않습니다.
## 웹페이지 전체 캡처 (추가)

링크로 받은 페이지를 앱에서 열 수 없을 때, 서버가 해당 사이트를 처음부터 끝까지 **이미지 한 장**으로 캡처해 돌려줍니다. 받은 이미지를 그대로 사진처럼 열어 치수/메모를 기록합니다.

- `server/` — Node + Playwright(Chromium) 캡처 서버, Railway(Dockerfile)로 배포
- `GET /capture?url=<주소>[&width=390][&desktop=1]` → `image/jpeg`
- 기본은 iPhone 폭(390px, 1.5x), 지연 로딩 이미지를 위해 끝까지 스크롤 후 촬영
- 높이 상한 10,000px (초과 시 `X-Truncated: true`), 응답 4MB 이하로 압축 (Vercel 한도)
- Vercel 에서는 `api/capture.js` 서버리스 함수(`@sparticuz/chromium`)로 같은 기능을 제공하고 `/capture` 로 연결됨
- 내부망/사설 IP 차단(SSRF 방지), 동시 2건 제한, `API_TOKEN` 설정 시 Bearer 인증

## 앱 (웹앱/PWA)

`server/public/` — 아이폰 사파리에서 열어 "홈 화면에 추가"로 앱처럼 사용합니다. 캡처 서버와 같은 Railway 서비스에서 함께 제공됩니다.

- 사진 불러오기 / 링크 캡처 → 편집 화면
- 치수선: 두 점을 탭하고 줄자로 잰 값(mm) 입력 → `1,250 mm` 라벨 표시
- 메모 추가, 선택 후 드래그로 이동(치수선은 끝점 개별 이동), 수정·삭제·실행취소
- 선 색상, 글자 크기 조절
- 원본 이미지와 편집 정보를 기기(IndexedDB)에 따로 보관 → 다시 열어도 수정 가능
- 저장·공유: 원본 해상도 PNG로 합성해 공유 시트/다운로드
- 설치형 PWA: 홈 화면 아이콘, 전체 화면 실행, 서비스 워커로 오프라인에서도 실행 (링크 캡처만 서버 필요)

설치: 아이폰 사파리에서 열기 → 공유 버튼 → "홈 화면에 추가". (안드로이드 크롬은 "앱 설치")
