# Photo MM

아이폰 사진과 스크린샷 위에 줄자로 잰 치수와 텍스트 메모를 기록하는 앱입니다.

> 현재 상태: 기획 단계입니다. 앱 기능은 아직 구현되지 않았습니다.

## 확정된 요구사항

- 줄자로 직접 잰 값을 입력합니다. 사진에서 실제 길이를 자동 측정하지 않습니다.
- 치수 단위는 mm로 고정합니다. 예: 1,250 mm
- 사진 위에 치수선을 배치하고 측정값을 표시합니다.
- 텍스트 메모를 추가합니다.
- 선 색상과 글자 크기를 조절할 수 있습니다.

## 첫 버전 개발 방향

1. 앱에서 사진 또는 스크린샷 선택
2. 두 지점을 선택하여 치수선 추가
3. mm 측정값 입력 및 메모 추가
4. 선 색상과 글자 크기 조절
5. 편집 내용 저장 및 표시된 이미지 공유

원본 사진과 편집 정보를 별도로 보관하여 저장 후에도 치수와 메모를 수정할 수 있도록 설계할 예정입니다.

## 후속 검토

- 사진 앱의 공유 메뉴에서 가져오기
- 확대 편집, 실행 취소, 마지막 스타일 기억
- 현장별 사진 분류 및 PDF 내보내기

스크린샷 촬영 직후 앱을 자동 실행하는 방식은 iOS 제약이 있어 첫 버전의 전제로 삼지 않습니다.
