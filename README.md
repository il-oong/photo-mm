# Photo MM

아이폰 사진·스크린샷에 **줄자로 잰 mm 치수와 텍스트 메모**를 기록하는 iOS 앱입니다.

## 현재 구현

- 사진 선택 및 기록 목록
- 두 지점으로 치수선 생성, mm 값 수동 입력 (소수점 두 자리까지)
- 텍스트 메모 추가
- 빨강·노랑·파랑·검정·흰색 및 글자 크기 조절
- 스타일 미리보기 및 마지막 스타일 기억
- 두 손가락 확대·이동, 치수선 끝점 및 메모 위치 변경
- 표시 수정·삭제, 최대 50회 되돌리기
- 원본 사진과 편집 정보를 별도로 저장하여 다시 편집
- 표시된 이미지 공유 및 저장하지 않은 변경에 대한 닫기 확인

사진에서 실제 길이를 계산하지 않습니다. 모든 치수는 사용자가 입력한 값입니다.

## 사용 순서

1. `사진 선택`으로 사진이나 스크린샷을 가져옵니다.
2. `치수선`에서 시작점과 끝점을 누르고 줄자로 잰 값을 입력합니다. 단위는 mm 고정입니다.
3. `메모`에서 사진을 눌러 텍스트를 적습니다.
4. 입력 창에서 색상과 글자 크기를 조절하고 `적용`을 누릅니다.
5. `수정`에서 글자를 눌러 다시 편집하거나 끝점·메모를 끌어 위치를 옮깁니다.
6. `저장`하면 앱 안에 기록이 남고, `이미지 공유`로 표시된 사진을 보낼 수 있습니다.

숫자는 천 단위 구분 없이 입력합니다 (`1250`). 화면에는 `1,250 mm`로 표시됩니다.
두 손가락으로 사진을 확대하거나 이동합니다. 편집 도구를 바꾸면 작성 중인 첫 점은 취소됩니다.

## 개발 및 실행

- iOS 17 이상, SwiftUI + UIKit
- Mac 및 iOS 17 이상 SDK가 포함된 Xcode 필요
- XcodeGen으로 프로젝트 생성 (앱 외부 라이브러리 의존성 없음)

```sh
brew install xcodegen
xcodegen generate
open PhotoMM.xcodeproj
```

Xcode에서 `PhotoMM` scheme과 iPhone 시뮬레이터를 선택하고 실행합니다.
실제 아이폰 설치는 Xcode의 Signing & Capabilities에서 자신의 Apple 개발 팀을 선택하고,
필요한 경우 고유한 Bundle Identifier로 변경한 뒤 진행합니다.
Windows에서는 소스 편집은 가능하지만 Xcode 실행·아이폰 설치는 할 수 없습니다.

## 검증

GitHub Actions의 Mac 환경에서 프로젝트 생성, iPhone 시뮬레이터 빌드 및 XCTest를 실행합니다.
테스트는 숫자 검증, 화면 크기별 좌표 보존, 원본 보존, 저장·복원·재수정,
잘못된 사진 처리, 손상된 기록 보존, 이미지 출력, 가장자리 글자 배치를 검사합니다.
테스트 결과는 Actions의 `ios-test-results`에서 확인할 수 있습니다.

실제 기기에서 확인할 목록은 [수동 검증 안내](docs/TESTING.md)에 있습니다.

## 저장 방식과 한계

- 계정·서버 없이 앱의 Documents/PhotoMM 폴더에 원본 사진과 JSON 편집 정보를 저장합니다.
- 사진 선택은 iOS 시스템 선택기를 사용합니다. 앱이 갤러리 전체를 탐색하지 않습니다.
- 원본 바이트는 보존하고 편집·공유용 이미지는 긴 변 최대 2,400px로 처리합니다.
- 앱을 삭제하면 앱 안에 보관한 기록도 삭제될 수 있습니다. 중요한 결과는 공유로 따로 보관하세요.
- 저장은 `저장` 또는 `이미지 공유`를 눌렀을 때 수행됩니다. 강제 종료 전 미저장 수정은 복구되지 않습니다.
- 아주 긴 메모는 작은 사진에서 잘릴 수 있습니다. 짧은 메모를 여러 개로 나눠 사용하세요.
- 사진 앱 공유 메뉴에서 가져오기, 캡처 자동 실행, 카메라 촬영, 폴더·PDF 기능은 이번 버전에 포함하지 않습니다.
- 앱 아이콘·App Store 배포·TestFlight 서명 설정은 후속 작업입니다.

현장에서 끝점을 누르기 편한지와 글자 가독성을 조정합니다.
